NoteTop is a simple overlay notepad for Windows. It stays on top of other applications, allowing you to quickly write down notes or use the built-in calculator without alt-tabbing. Written entirely in PowerShell.
Has features like: Built-in calculator, always on top, minimalistic.
Installation is easy. Run the "Start" file. Here you are!
If a security prompt appears, choose "More info" and then "Run anyway".
